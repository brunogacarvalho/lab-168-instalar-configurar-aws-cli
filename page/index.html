02 · CONCEITOS

Componentes utilizados

Amazon EC2

Serviço que disponibiliza capacidade computacional na nuvem. Neste laboratório, uma instância Linux foi utilizada como ambiente para instalar e executar a AWS CLI.

SSH e PuTTY

O SSH permite acessar remotamente a instância Linux. O PuTTY foi utilizado no Windows como cliente SSH, com autenticação por chave privada.

AWS CLI

Ferramenta que permite executar operações nos serviços AWS pelo terminal. Os comandos podem consultar recursos e automatizar tarefas sem utilizar o console web.

AWS IAM

Serviço de gerenciamento de identidade e acesso. Permite controlar usuários, grupos, permissões e políticas que determinam quais ações podem ser executadas.

03 · PRÁTICA

Comandos utilizados

Alguns dos comandos principais executados durante o laboratório.

Verificar a versão

Confere se a AWS CLI está instalada e disponível no terminal.

aws --version

Configurar a AWS CLI

Define credenciais, região padrão e formato das respostas.

aws configure

Consultar usuários

Retorna os usuários IAM existentes na conta.

aws iam list-users

Consultar políticas locais

Lista as políticas gerenciadas pelo cliente.

aws iam list-policies --scope Local

Recuperar uma versão de política

Obtém o documento JSON de uma versão específica da política IAM.

aws iam get-policy-version
